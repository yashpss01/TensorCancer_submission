# Submission output

The required `matching_results.tsv` and `candidate_pairs.tsv` are intentionally absent from this branch: the frozen matcher has only been evaluated on a labeled training holdout, and full test inference has not been run. The runnable inference steps are documented in `code/business_entity_resolution/README.md`.

Do not upload the training-holdout metrics in `reports/` as a Portal submission. Run inference on the provided test files, validate both TSVs, then package and submit them.
